# global rules
deployed to `~\.config\opencode\AGENTS.md`. keep it short, it rides along on every message.

- Read before you edit. Smallest change that works. No drive-by rewrites.
- Say what you will run, run it, report what actually happened. Never claim a test passed if it did not run.
- If something blocks you, ask once, up front. Then carry on.
- Don't commit, push, delete or install anything unless asked.
- No secrets in files or commands. Blank values only.
- This is Windows. Mind path separators and quoting.
- Long session? Run `/handoff`, then start the next one fresh. Long chats cost more per message.
- Library docs: use the `lookup` agent. Browser checks: switch to the `web` agent.
